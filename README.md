# brownian_motion

ブラウン運動の解析（jsec2021）。HSV条件に合う画素の重心を追跡し、一定コマ数ごとの平均移動量を除いた振動を表示します。

```sh
uv sync
uv run main.py
```

画像をクリックすると、その位置と色を使って追跡を開始します。`bar`ウィンドウのH・S・Vで色の許容幅、RECTで探索範囲の直径を調整できます。左上のメニューから終了、解析のリセット、カメラ切り替え、軌跡と振動の表示切り替えができます。終了はEscまたはqでも可能です。

設定値は`main.py`の先頭の定数にまとめています。カメラの希望解像度にかかわらず、探索には実際に取得した画像サイズを使います。座標は小数で保持します。未検出のフレームでは座標を保持し、解析には追加しません。対象の選び直しとカメラ切り替えでは解析履歴をリセットします。軌跡と解析履歴は既定で直近3750件（目標15FPSで約250秒分）を保持します。

- `main.py`: 初期化、取得、重心計算、解析、描画、終了までの処理の流れ
- `lib/interaction.py`: マウス操作の状態とコールバック
- `lib/camera.py`: カメラの設定、取得、切り替え、解放
- `lib/calc.py`: HSV条件による重心計算
- `lib/analyze.py`: コマ落ち率と振動の解析
- `lib/ui.py`: 設定バー、メニュー、軌跡、グラフの描画

`fonts/meiryo.ttc`があれば日本語メニューを使い、なければ英語の短いラベルで表示します。GUIとカメラを使える環境が必要です。

依存関係は`pyproject.toml`で管理し、`uv.lock`にバージョンを固定します。Pythonは既定で3.13を使用します。依存関係を追加する場合は`uv add パッケージ名`を使います。


このMacBook Air（M4・10コアCPU・24GBメモリ）では、1920×1080、カメラ取得30FPS、解析ループの目標15FPSを初期設定にしています。カメラ台数は確認できた内蔵カメラとiPhoneの2台です。解析区間は94コマ（目標15FPSで約6.25秒）です。これらは実測した性能上限ではなく、カメラが設定を反映するか、目標FPSを維持できるかは実行時に確認してください。

実機確認ではカメラ番号0が黒画像を返し、番号1では映像を取得できたため、起動時は`CAMERA_INDEX = 1`を使います。接続状態で番号が変わる場合は、`main.py`の`CAMERA_INDEX`を変更してください。
